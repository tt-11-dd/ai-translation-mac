# Agent Note: 打开时自动翻译

Status: implemented

## Problem

复制唤醒已能填入剪贴板，但仍需再点「翻译」。设置里已有 `autoTranslateOnOpen`，却只接在图片 OCR 路径，文案也写成「识别图片后自动翻译」，复制唤醒用不上。

## Decision

复用同一开关覆盖「剪贴板文本填入」与「图片 OCR」两条打开路径；默认关闭，避免无意打 API。指纹命中（与上次填入/译出相同）只回填、不自动翻译，防止「译完自动复制」把译文再翻回去。清空后若指纹仍命中，仍回填原文框，方便继续改。

## Alternatives considered

- 另开「复制唤醒自动翻译」开关：多一个设置项，与 OCR 行为重复，否决。
- 默认开启：省一次点击，但会在每次唤起时耗 Token，否决。
- 指纹命中也自动翻译：易与「译完自动复制」形成中英来回翻，否决。

## Consequences

- 收益：复制 → 快捷键即可开翻；OCR 与复制共用同一偏好。
- 代价：依赖剪贴板指纹约定；关「打开时读取剪贴板」时开关禁用但值仍保留。
